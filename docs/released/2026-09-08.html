GitHub Copilot matches frontier model quality at two-thirds the cost

A document-reading agent that structures as it goes cuts costs 53%

Document-querying agents pay the same reading cost repeatedly; adaptive structuring makes that cost accumulate as reusable knowledge.

Agents querying unstructured documents (filings, contracts) burn up to a million tokens per question. An arXiv preprint proposes 'agentic data cracking': a sub-agent forks from already-loaded context at marginal cost, extracting structure for future queries. On FanOutQA, costs fell 53% with no accuracy loss. Does your document-agent architecture accumulate what it already paid to read?

Each item today removes a constraint practitioners had filed under 'infrastructure given': fused GPU kernels, edge routing, memory governance, eval fragmentation, retrieval architecture. The practical question this week is which of those assumed ceilings your team is still building around.

llama.cpp closes the Vulkan gap for DeepSeek inference, cutting decode time 32%

DeepSeek-V4 inference on Vulkan hardware now runs the same fused ops CUDA and Metal have had for months.

Vulkan was the last major backend running DeepSeek-V4's hyper-connection ops as an unfused chain, costing roughly 32% of decode time on AMD Strix Halo hardware. Build b10844 fuses all three ops into register-level kernels; one dispatch replaces about 137 ordered executions per site. Pull b10844 and profile your DeepSeek-V4 decode throughput against the prior build.

Reasoning agents now run at the edge, without a data centre link

Agentic workloads that required data-centre routing now have a documented local path on Jetson hardware.

NVIDIA's technical blog walks through deploying compact reasoning models on Jetson edge hardware, using Nemotron 3.5 Lightning and Qwen3-27B as examples. Two techniques, NVFP4 quantisation and speculative decoding, combine to lift generation speed; the vendor's own numbers show each compounds the other. Benchmark both models against your specific agent workload before committing to one.

NVIDIA's memory-driven agent recipe separates context from authorisation at runtime

Persistent agent memory was a storage problem; NemoClaw's recipe makes it a governance architecture.

Enterprise agents forget context between sessions. NVIDIA's NemoClaw Chief of Staff recipe, open on GitHub, addresses this with three layers: Markdown knowledge pages, a SQLite obligation ledger, and a sandboxed runtime where memory informs actions but never authorises them. Benchmarks against a retrieval baseline ship with the repo. Clone nemoclaw-community and run the offline walkthrough before wiring live credentials.

One harness now runs agents across 80 benchmarks, with results public

Agent eval pipelines now have a shared harness baseline, not dozens of bespoke integrations.

Porting agents across dozens of benchmarks has meant rebuilding integrations each time. Harbor Adapters unifies more than 80 benchmarks into a single harness; the authors ran 8 models across 54 of them. No evaluated model clears 30% on Harbor-Index, the curated 82-task subset. Adapters, results, and the index are open-source. Run Harbor-Index against your own agent before trusting vendor scores.

A single-transformer encoder retrieves document pages at twice a rival's speed

Document retrieval encoders carried a separate vision tower as fixed overhead; NeoMME folds both into one pass.

NeoMME trains a single bidirectional transformer on text and images together, skipping the separate vision tower most retrievers carry. The 260M model encodes 51 document pages per second, roughly twice ColModernVBERT's throughput; late-interaction index storage shrinks 255-fold. Checkpoints are public under Apache 2.0. Pull the 260M checkpoint and run it against your document retrieval pipeline.
