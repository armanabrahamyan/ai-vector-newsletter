Governance is the gap. Across containment failures, macro distortion, and fragmented agent stacks, the common thread is not capability shortfall; the architecture for oversight has not kept pace with the systems it is meant to govern.

Currents

1 item

Memory is the new bottleneck. A single early result, not yet replicated at scale. The direction it points is real: long-horizon agents are hitting memory ceilings before capability ones, and the fix is architectural.

Berkeley's belief-state trick halves the memory cost of long agent tasks

Context summarisation keeps long-horizon agents running, but quietly degrades performance. ABBEL, from Berkeley AI Research, isolates and grades each summary as a belief state rather than compressing history wholesale. In collaborative coding tests, it closed half the performance gap versus full-context models, using 50% fewer training steps. Raise it at your next long-context agent architecture review.
