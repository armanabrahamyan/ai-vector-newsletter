The Pulse · Story of the day

Every coding agent tested writes vulnerable code, even when it works

Functional correctness was the security proxy for agent-generated code; it is not.

An arXiv preprint tested 12 coding agent configurations on 186 real-world tasks. The sharpest gap: SWE-Agent with Claude 4 Sonnet solved 57% of tasks correctly, but only 11.8% of those solutions were secure. Adding vulnerability hints to prompts didn't close the gap. Benchmark and dataset are public; run it before shipping agent-written code to production.

What runs through today's stories is a single demand arriving simultaneously at four different layers: proof that the system behaved correctly, not assurance that it was designed to. Governance, deployment trust, infrastructure benchmarks, and retrieval design are all being rewritten around the same audit obligation.

Microsoft shifts AI governance from written policy to live runtime enforcement

AI governance sign-off now requires runtime proof, not a documented policy alone.

Microsoft's published architecture names nine governance domains and four functions: policy, control, visibility, and proof. The Agent Governance Toolkit (open-source) and AI Gateway enforce rules at runtime, not at sign-off. When your regulator asks for audit evidence, can your current AI stack produce it from live telemetry, or only from documentation?

Roblox's 'Prompt to Prod' programme targets the gap between generating code and trusting it enough to deploy without human review. NVIDIA claims 30x more agentic throughput per watt on new hardware

Infrastructure procurement decisions now hinge on tokens per watt, not raw compute headroom.

Agentic workloads now consume 15 times the tokens of ordinary chat, per OpenRouter data, making power efficiency the real infrastructure constraint. NVIDIA's own AgentX benchmark, vendor-run and pending SemiAnalysis review, shows Vera Rubin NVL72 at 30x the throughput-per-megawatt of current Blackwell. When does your power budget, not your token budget, become the binding constraint in your next data-centre contract?

In regulated finance, auditability beats accuracy as the retrieval bar

FP&A retrieval systems now face an auditability bar, not just an accuracy one.

An arXiv preprint argues that search-augmented generation for financial planning should be judged on audit trails, not just correct answers. On FinanceBench's 145 questions, the ontology-grounded KDAF framework matched simpler retrieval on accuracy but led on citation traceability (F1 0.515 vs 0.463 for keyword search). Which auditability standard does your FP&A vendor actually meet?

Today's practical wins each move a cost boundary by changing where a decision gets made, not what model makes it. Routing, resumption, interception, orchestration, and prompt framing all shift the same lever: defer the expensive call until cheaper options are exhausted.

DoorDash routes only 10% of messages to costly AI, cutting moderation bills

Content moderation at scale is now a routing problem, not a model-quality one.

Calling an AI language model 4 million times a day was too slow and too expensive. DoorDash's SafeChat filters obvious cases with a fast in-house classifier (under 100 milliseconds), then sends only the ambiguous remainder to a language model for multi-axis scoring. Map your message volume against that single-digit unsafe-rate finding before choosing your moderation stack.

A planning skill for coding agents splits fog-of-war into parallel threads

Greenfield agent planning now has an orchestration layer; ad-hoc context juggling was the only option before.

The /wayfinder skill, from Matt Pocock's "AI Skills for Real Engineers" project (220,000 GitHub stars), tackles greenfield planning by spawning parallel agent threads: research, prototyping, and grilling sessions. Each thread gets a map (shared context) and a ticket (specific task). Pull the skill; run it against your next underspecified project.

Kernel hooks intercept AI agent traffic in Kubernetes without a code change

AI gateway controls previously meant application changes; kernel-level hooks now intercept traffic transparently.

Dan Finneran's conference talk (Cisco/Isovalent) demonstrates kernel-level socket hooks intercepting AI API calls inside Kubernetes clusters, enabling prompt filtering, model swapping, and token limits without modifying source code or restarting containers. It's a proof-of-concept tied to an active Kubernetes working group. Raise it at your next agent-infrastructure design review before specifying a gateway layer.

Prompt wording alone shifts coding-agent cost without changing the task

Token count was the efficiency proxy for coding agents; prompt wording and harness now set the real cost.

An arXiv preprint (arXiv:2608.01347) shows that prompt wording shifts reasoning and verification behaviour without changing the task, and that effort-control gains measured under one harness evaporate when the harness changes. The real efficiency metric is cost per successful task, not token count. Rerun your effort-control settings; the gains you measured under one harness won't transfer.

A hybrid detector catches AI-generated fake reviews that fooled earlier systems

Recommendation fraud now arrives as coordinated AI-generated profiles, not detectable by text or graph signals alone.

Language model agents can now generate fake reviews, ratings, and user profiles at scale, defeating detectors that look at text or graph structure alone. TH-GNN, an arXiv preprint, combines both signals with timing patterns and reaches an F1 score of 0.87 across five attack types. Raise it at your next fraud-detection architecture review.
