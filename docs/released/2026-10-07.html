Pass rates measured agent capability; backend state now measures whether agents actually finish the work.

Microsoft and Hugging Face's ThinkingBox benchmark grades agents on what the database actually contains after a task, not on tool-call logs. The Big Picture

4 stories

Every story today breaks on the same structural assumption: that the boundary between an agent and sensitive data was enforced somewhere downstream. It was not. The attack surface is not a misconfiguration to patch; it is the default architecture of systems already in production.

A public lead form let attackers drain Salesforce CRM data silently

Agentforce's public intake forms were an unauthenticated entry point for data theft, not just lead collection.

Zenity Labs embedded a hidden instruction inside a Web-to-Lead submission; when an internal user asked Agentforce about recent leads, the agent queried the Accounts table and exfiltrated deal data via a DNS request, bypassing Salesforce's URL-redaction layer. Salesforce has since patched the mechanism. Which perimeter controls does your security team currently assume cover public-facing Agentforce intake forms?

MCP's trust model lets malicious prompts hop across agent chains

Agent-to-agent trust was an assumed internal safeguard; five documented exploits make it an attack surface.

In five months, Google, JP Morgan Chase, and three other organisations acknowledged attacks exploiting MCP, the protocol agents use to communicate internally. A malicious prompt injected into one agent propagates to others because internal agents trust each other by default. Which team in your organisation actually owns the credential scope decisions when a new MCP server joins your network?

Google maps the unsolved security gaps in autonomous AI agents

Agentic privacy had no shared threat map; Google's 50-author report draws the first one.

Google Research, with more than 50 co-authors, identifies three structural gaps every agent shares: unpredictable behaviour, broad data access, and no runtime norm-checking. The proposed fix is a contextual policy engine that evaluates each action before data leaves the workspace. Does your agent architecture include that gate before your next deployment review?

Today's releases share a structural shift: vendor lock-in and benchmark opacity are both losing their assumed permanence. Open weights dissolve re-embedding debt; production-calibrated evals replace vendor claims. The cost ceiling on agentic retrieval is now measurable, not negotiated.

Google's open embedding model lets you escape re-embedding costs when vendors deprecate

Stored embedding vectors were hostage to the vendor who generated them; open weights end that.

Proprietary embedding models create a silent debt: when a vendor retires one, you repay the cost of re-processing every stored vector. EmbeddingGemma 2 ships under Apache 2.0, meaning you can self-host or switch providers without that penalty. Simon Willison flags this as the structural reason closed embedding models are the wrong default.

Google DeepMind's open embedding model unifies text, code, audio and video

Multimodal retrieval pipelines defaulted to closed APIs; open weights now run offline.

EmbeddingGemma 2 (740M parameters, Apache 2.0) embeds text, code, images, audio, and video in a single shared space, running on-device at under 600MB RAM. Weights are public on Hugging Face. Pull the model and run your current retrieval benchmark against it; the memory footprint makes on-premise deployment viable today.

GitHub's code-review benchmark is built from 100 million real pull requests

Code-review agent quality was judged by vendor claims; a production-calibrated public benchmark now exists.

Existing code-review evals rarely reflect production workloads. ReviewBench samples 219 pull requests across 187 repositories and 19 languages, weighted toward multi-file changes where review quality matters. Senior engineers independently re-labelled every finding; agreement hit 96.6%. The dataset and evaluation harness are public. Run your code-review agent against it before your next tooling decision.

Agentic retrieval beats keyword search but costs 160 times more per query

Retrieval quality now has a measurable cost ceiling, not just a capability floor.

Dense retrieval matches surface-level words; an arXiv preprint shows a reasoning-loop pipeline scores 8.7 points higher on standard retrieval benchmarks using the same embedding model. The tradeoff is steep: 107 seconds per query against 0.67 seconds, plus roughly 770,000 tokens consumed. Before adding agentic retrieval to a multi-step pipeline, price the token bill against your query volume.

A new benchmark reveals agents complete tasks but fumble recovery

Nominal completion scores hid phase-dependent recovery failures; a benchmark now separates them.

An arXiv preprint introduces UndoBench, spanning 36 workflows and 36 fault scenarios across 8 enterprise domains. Agents hit 83.54% task completion but only 46.72% recovery success; naive retry produced duplicate external effects in 53.28% of trials. Add UndoBench's fault scenarios to your next agent evaluation before trusting completion rates in production.
