The Big Picture

4 stories

Each story moves the point of assurance away from the provider's own word: outside evaluators, per-action intent checks, a second chip supplier, and measured attacker weakness. The evidence is uneven, though, since two are proposals or vendor claims and one is a single preprint.

The EU wants frontier AI models tested by outside evaluators with proven independence

Vendor assurance for frontier models now has to name testers the provider cannot pay or steer.

The EU AI Office has proposed qualification and independence rules for external evaluators of the most powerful general-purpose models, with a scoring system planned. Evaluators must be free of provider financial or operational influence. Twenty organisations were selected for a July workshop, 19 attended. If providers can't pick their own testers, who in your vendor contracts holds the right to audit?

Uber checks whether each AI agent action fits the request, not just the permissions

Agent sign-off now needs per-agent intent and constraint definitions, where access-permission reviews once sufficed.

Uber Engineering says identity and API controls can confirm an agent may touch a resource, not whether the action suits the request. Its framework registers each agent, checks proposed actions at runtime through guard hooks, and replays recorded traces. Its strongest control was explicit per-agent constraints. If vendor agents accept no hooks, who enforces intent in your stack?

Today's best computer-use agents exploit fewer than one in eight real web app flaws

Penetration-testing budgets can still treat screen-driving agents as weak attackers, with exploitation rates under 12%.

HackWorld, an arXiv preprint, tests computer-use agents (AI that operates a screen like a person) against 36 real web applications with injection and authentication flaws, in capture-the-flag format. Exploitation rates stay below 12%; agents botch multi-step attack planning and misuse security tools. If agents gain that skill, who in your security team owns testing them?

Microsoft's open-source plugin cuts coding-agent costs by up to 31% by learning from past sessions

Repeat-repository agent spend now falls with experience, where fixed cost-saving plugins helped only some repositories.

Microsoft Research's TokenEconomizer reads an agent's past sessions in a repository, then adds one-line notes, prunes unused tools and flags failure loops. Across 277 bug-fixing tasks, costs fell 18.4-30.9% with success broadly stable. It works alongside Claude Code without modifying the agent, and the plugin is open-source. Install it on one repository you revisit often, then compare spend after six tasks.

Eight leading AI models can place options trades, but none profits reliably

Trading-agent pilots now get judged on risk and structure choices, where stock-direction accuracy once passed for skill.

LiveOption, an arXiv preprint, tested eight language models, including GPT, Gemini and DeepSeek, across three options-trading scenarios using 2025 market data. The models produced executable trades, but none delivered statistically reliable profit. Judge trading agents on risk handling and structure selection, not directional calls, before funding any pilot.

A local text-to-SQL model answers half of database questions, cutting hosted-agent costs a third

Database agent budgets now price a local first pass at 33.3% savings, where every query once hit the hosted model.

A compression method builds a small model from a big one's own weights

Small-model builds can now start from a teacher's weights, where training from scratch once demanded vast data.

Concertina folds each group of adjacent layers in a large model into one shared block run repeatedly, with small learned corrections restoring each layer's behaviour. Built from Qwen3-4B, a 2.27B model distilled on 22B tokens keeps about 84% of the teacher's average score and beats Qwen3-1.7B. The code is public, and the results come from one teacher, Qwen3-4B.
