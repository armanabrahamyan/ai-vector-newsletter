Anthropic's Claude extension on Cursor was backdoored, exposing 5,000 developers

Verified publisher accounts are now a confirmed supply-chain attack vector for AI developer tools.

Anthropic's Claude extension for Cursor was backdoored for roughly 12 hours via its official publisher account; version 2.1.313 reached up to 5,000 developers before a clean update shipped. The malicious build installed a persistent SSH backdoor targeting source code and credentials. Anthropic had not issued a customer warning as of Friday. Auto-update settings are now under urgent developer scrutiny.

ChatGPT's sandbox let attackers hijack accounts through a library flaw

ChatGPT Enterprise security reviews now include sandboxed iframe libraries, not just the model's own API surface.

Parameter Labs found that ChatGPT's HTML preview iframe escaped its sandbox via MathLive's postMessage handler, which used innerHTML to inject a new unrestricted iframe; YouTube's oEmbed endpoint then reflected executable JavaScript. Any shared ChatGPT link could exfiltrate private data. OpenAI patched it and paid a $5,000 bounty. Audit third-party library message-passing surfaces before shipping.

Prompt order, not capability, determines which agent leads a swarm

Agent swarm coordination was assumed to follow model quality; prompt order shapes it just as much.

Researchers ran eight agents from four models through simulated outage scenarios without a designated leader. Two factors drove who took charge: the underlying model and the agent's position in the prompt list. Listing order is as influential as model choice, so audit your swarm configs before assuming capability determines coordination.
