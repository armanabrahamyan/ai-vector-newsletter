llama.cpp now sandboxes tool calls inside Docker containers

Local inference tool calls ran unsandboxed by default; container isolation now ships in the runtime.

Tool calls in local inference servers have run unsandboxed, letting a malicious function escape the process. llama.cpp build b10328 adds Docker-based isolation for server-side tool execution via PR #26507. If you run agentic workloads on a self-hosted llama.cpp server, pull this build before wiring in untrusted tools.

Claude Code auto mode blocks prompt injection better than humans do

Confirmation fatigue made human approval a weaker safety layer than auto mode.

From 14 August, auto mode becomes the default in Claude Code for Pro, Max, and Team plans. In a 1,053-person test, only 13.6% of humans refused a dangerous command; auto mode blocked 89%. A commissioned third-party evaluation found zero successful prompt-injection attacks across 720 attempts. Log every blocked action as you roll it out.

Cloudflare open-sources a persistent agent runtime built to scale beyond containers

Agent state persistence now has an open-source runtime option, where ephemeral containers were the only path.

Stateless containers, Cloudflare argues, won't scale to billions of concurrent agents. Its open-source @cloudflare/computer package runs agent state in isolates, spinning containers only when needed, targeting under 10% container use. A shared SQLite filesystem links both. Still an early preview; clone the repo and diff its persistence behaviour against your current agent state layer.
