The Pulse · Story of the day

Long-context inference gets 30x faster by skipping most attention calculations

Long-context serving costs were set by dense attention; sparse block selection now cuts that by 30x.

Processing a 128,000-token context through a language model is expensive because every token attends to every other. FlashPrefill V2, an arXiv preprint, skips most of those calculations using block-sparse patterns, achieving a 30x speedup over a dense baseline on NVIDIA H20 hardware. It integrates with SGLang today. Benchmark against your longest production contexts before committing.

Customer-service agents now need workflow-level compliance, not just action blocks

Customer-service agent deployments now require workflow-wide policy checks, where single-action guardrails were the standard.

Single-action guardrails catch forbidden moves but miss omitted steps. PolicyGuide (an arXiv preprint) compiles policy into a workflow graph and runs a verifier at each user turn; compliance scores rose from 0.42 to 0.62 across airline, retail, and telecom scenarios. Before your next agent deployment, map which procedural gaps your current guardrails leave.

Retrieved memories can trap language models into wrong reasoning

Correct retrieval was the assumed ceiling for memory quality; it is now the floor of a harder problem.

An arXiv preprint introduces MemTrapBench, a benchmark covering two failure modes where retrieved memories hurt rather than help: Reasoning Fixation and Belief Distortion. Across five memory frameworks, every tested strategy underperformed the no-memory baseline, with the strongest dropping more than 10%. Run MemTrapBench against your memory stack; if you score below baseline, AdaptiveMem is the named mitigation.

Google open-sources a compiler that runs AI models on encrypted data

Encrypted-data inference shifts from research curiosity to a compiler you can clone today.

Google's HEIR compiler adapts existing PyTorch models to run on homomorphic-encrypted inputs, so the server never sees raw data. The toolchain is open-source with demos included. Overhead is real: addition costs ~100ms per operation, and Google ships benchmarking code but no language-model figures. Pull the repo and run HEIR against your smallest production classifier before committing to the architecture.

Cloudflare's agent browser skips Chromium's overhead to cut browser-use costs

Browser-use agent costs now scale with task count, not with a full Chromium instance per session.

Full Chromium browsers were built for humans; Cloudflare's Kitesurf runs browser components in isolated WebAssembly/Rust environments on Workers, supporting Playwright and Puppeteer with lower resource overhead. Each page gets its own sandboxed worker. Cloudflare says open-sourcing is planned; wire Playwright against Kitesurf in your next browser-use agent build once it lands.
