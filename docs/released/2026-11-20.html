OpenAI measures how much coding agents speed up its own AI research

OpenAI has now published measured agent speedups inside its own research, moving beyond benchmark scores as evidence.

OpenAI has published its first measurement of how far coding agents accelerate its own research, finding the gains uneven: strong on some tasks, weak on others, hence the "jagged frontier". The source excerpt was unavailable, so the figures are unknown. Anthropic lets Claude Code changes merge with no human approval when the risk is low

Code-review policy now scales human approvals to a change's risk tier, where it once scaled to lines read.

Anthropic's Claude Code team routes human review by risk: none for documentation or flagged internal features, one approver for medium changes, two for high, always for CI workflows. By Anthropic's own account, merged pull requests more than doubled between June and September while reverts fell over 40%. When agents write the code, who in your organisation owns the risk tiers?

Databricks maps four ways to let AI agents work inside regulated, auditable systems

Agent sign-off in regulated firms now depends on who holds authority at each step, not just model accuracy.

Databricks' forward-deployed engineers sort agent work into four patterns: deterministic controls stay in charge, agents iterate against a deterministic judge, humans own judgement calls, and bounded autonomy runs inside a set envelope. In a reconciliation, the agent investigates the failure; it cannot become the control. Sort your use cases into these four before granting agents authority.

PIPETTE defenders reach near-zero attack success on static attacks and resist adaptive ones

Red-team scorecards now need attack diversity, where raw success rate once stood as the proxy for hardening.

Attack success rate in red-teaming does not predict how robust an agent becomes. Two leading reinforcement-learning attackers, RL-Hammer and PISmith, keep rediscovering the same tricks. PIPETTE, an arXiv preprint, rewards attack variety and trains defenders on-policy, reaching near-zero attack success on AgentDojo and ASB while keeping task performance close to the undefended baseline.

Three AI readers from different providers fact-check text as well as the best single model

Grounding checks for AI-written summaries now come with a per-claim evidence trail, where one model's verdict once stood alone.

If this holds, fact-checking AI summaries may not need one strong model. GauntletScore, an arXiv preprint, asks three readers from different providers typed questions, logs each answer in an evidence ledger, and counts a contradiction only when two agree. It scores 79.51 balanced accuracy, level with the best published checker; per-claim predictions and the scoring script are public.

A small model handles routine agent decisions and cuts cost by up to 91%

Routing routine agent steps to small models cuts episode cost 75-91% across three benchmarks, a preprint shows.

Early signal that agents needn't call a large model at every step. AnyS1, an arXiv preprint, mines decision points from over 1,000 public skill documents and trains a 4B pointer model to pick routine options, escalating when unsure. Episode cost falls 75-91% across three benchmarks; the SkillDP dataset is public.

A new benchmark tests whether AI can judge engineering designs without running a simulation

Engineering sign-off tests now ask what a model concludes from past runs, where they once scored software operation.

If this holds, engineering judgement is a gap leaderboards miss. EJBench, an arXiv preprint, draws tasks from battery cold-plate simulations; answers come from converged simulations, not LLM judges. The best of ten frontier models, GPT-6 Astra, scores 0.71, with similar confidence on right and wrong answers. Splits, harness and leaderboard are public.
