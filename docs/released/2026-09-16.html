The Pulse · Story of the day

Three frontier labs back a common standard for independent AI safety auditors

Model-risk teams now have a named external audit standard, where self-reported safety was the only reference.

The AI Evaluator Forum's AEF-1 standard, co-signed by xAI, OpenAI, and Anthropic, sets baseline rules for independent AI auditors: access rights, conflict-of-interest rules, funding disclosures, and recusal requirements. Anthropic has gone further, promising auditors desk space, access badges, and laptops comparable to internal risk teams. The standard gives procurement teams a concrete benchmark to apply when selecting evaluators.

When your agent summarises a filing, who in your org verifies the evidence trail before anyone signs?

4 stories

Each story this week patches a different layer of the same broken assumption: that agent deployments could be evaluated, guarded, orchestrated, and monitored using tools built for stateless services. The fixes are unglamorous and additive, which is precisely what makes them worth picking up now.

A 24-point reliability gap hides behind every agent benchmark average

Agent benchmarks reported a capability score; they buried the repeatability score beneath it.

Standard agent evals report average success rates; IBM Research's ALTK-Evolve work on AppWorld shows a GPT-4.1 agent scoring 77.4% but passing all five repeated runs on only 53% of tasks, a 24-point gap. Consistency guidelines, built on a resampling diagnostic, halve that gap. Run the Consistency Analyzer against your shakiest agent workflow before relying on it in production.

A safety auditor for computer-use agents closes a 16-point accuracy gap

Practitioners deploying computer-use agents now have a tested guard framework, where static prompt filters were the only option.

Existing safety guards check prompts and responses; HazardAuditor watches what agents actually do in browsers, terminals, and file systems at runtime. Its Guard Policy Optimization training technique lifts safety classification accuracy by up to 16.5 percentage points over the prior best. Code, models, and evaluation artefacts are public. Postgres can run durable agentic workflows without a separate orchestrator

Durable agentic workflows now run on Postgres alone, where Temporal or Step Functions were the default.

Kestrel Workflows skips Temporal and AWS Step Functions entirely, using SELECT FOR UPDATE SKIP LOCKED to turn a Postgres table into a crash-safe work queue. Primary-key checkpoints enforce idempotency; a lease-and-sweeper pattern handles worker failures. Wire SKIP LOCKED into your next agentic workflow prototype; the orchestrator you were about to add is the dependency you don't need.

Currents

4 items

Each story today sits in Currents because the finding is real but the production path is not yet clear. Taken together, they sketch a consistent direction: the next round of AI cost and capability gains will come from rethinking training pipelines and inference conventions, not from scaling.

Reordering retrieved passages cuts language model compute costs by up to 36%

Retrieval chunk ordering was a convention; it is now a provably optimisable cost lever.

Every production retrieval-augmented system fixes a single global chunk order, assuming it minimises cache reuse costs. An arXiv preprint proves that assumption fails beyond two chunks, and that the optimal order follows a merge-sort-style hierarchy over requests. On three real retrieval benchmarks, the hierarchy-derived layout cut prefill computation by 17-36%, with gains widening at greater retrieval depth.

Google flips tool-training on its head by generating answers before questions

Tool-use training data was the bottleneck; an answer-first pipeline now clears it at near-perfect yield.

Standard tool-training pipelines start with a user query, then search for a solution. ToolGrad reverses this: generate the tool-use chain first, then annotate the query. Presented at ACL 2026, the method hit nearly 100% data-generation pass rate and fine-tuned Gemma models matched top proprietary models on an out-of-distribution benchmark. Raise it before your next training-data procurement decision.

Frontier models nail crypto transaction amounts but pick the wrong accounts

Crypto accounting automation was an amount-matching problem; account selection is where frontier models actually fail.

An arXiv preprint tests 12 models on 118 crypto-asset journal-entry tasks across seven organisations. Models matched base currency amounts 97.8% of the time but selected the correct accounts only 56.3% of the time. If you're scoping language models for crypto accounting automation, that account-selection gap is the number to stress-test, not the headline accuracy score.

Game-trained AI transfers to financial research, but harness design decides

Reinforcement learning environment design now determines skill transfer, not model size or base capability.

Good Start Labs trained a 30-billion-parameter model inside the railroad strategy game 1830, then tested it on financial research tasks. Only the multi-turn terminal-agent design improved performance on the Finance-Agent benchmark; single-turn training did not. A single podcast interview is the sourcing. The multi-turn harness is publicly documented and the benchmark covers five distinct financial attack types.
