The Pulse · Story of the day

Reordering GPU jobs, not adding hardware, lifted utilisation by 33 points

GPU scheduling order is now a capacity decision, not a tiebreaker applied after capacity is settled.

A constraint-aware scheduler benchmarked against a first-in-first-out baseline across seven scenarios recovered 33 percentage points of utilisation on identical hardware. Priority-weighted output rose up to 105%. The mechanism: treat real-time demand as a curve, not a fixed reservation, then fill troughs with batch work in priority order. Audit your reservation policy before your next cluster procurement.

Four stories today each expose a different floor that agentic deployment has not yet reached: transactional integrity, workforce planning, adversarial robustness, and open-ended reasoning. The gap between what agents demonstrably do in production and what governance frameworks assume they can do is widening, not narrowing.

Multi-step agents need database-style guarantees to stop mid-task failures

Agent reliability now demands transactional guarantees; ad-hoc rollback logic no longer suffices.

When an autonomous agent fails mid-task, partial writes and broken state are the real cost. An arXiv preprint proposes four database-style guarantees reinterpreted for agent execution, reporting a 10.6% benchmark gain over Claude Code. When your agentic pipeline fails halfway through, who owns the rollback — and is that responsibility designed in or assumed?

Grab cut routine analyst work by a third using production AI agents

Analyst headcount planning now starts from agent self-service rates, not ticket volumes.

Grab's analytics agents now handle 90% of data-pull requests without human involvement, up from 63% in March; mechanical analyst tickets fell from 44% to 30% between February and June. The system runs on 5,000 certified tables and a five-level autonomy model. If you're scoping an agentic analytics rollout, benchmark against these self-service rates before setting headcount assumptions.

An AI compliance judge fails keyword-stuffing attacks on crypto promotions

Aggregate accuracy scores on principle-based regulation now mask adversarial collapse, not measure deployment fitness.

Principle-Bench (an arXiv preprint) tests language-model judges on 168 UK Financial Conduct Authority cryptoasset promotion scenarios across four axes: accuracy, paraphrase robustness, adversarial robustness, and calibration. A 120-billion-parameter judge drops from 0.74 to 0.27 accuracy under keyword-stuffing. Which of these four axes has your compliance judge actually been tested on?

Frontier AI agents still can't do open-ended research, two case studies show

Teams betting on autonomous AI research agents inherit a documented failure mode, not a theoretical one.

Narayanan and Kapoor ran frontier agents on two unpublished research questions, giving each thousands of dollars in compute and six days. Both agent papers were rejected outright. The agents abandoned ambitious targets within day one, spent less than half their budget, and doubled down on failing directions instead of backtracking. If these findings hold, recursive self-improvement timelines need revisiting.

Hands-On

5 stories

Each story today hands practitioners a hidden cost that the default setting, the published claim, or the architecture diagram quietly conceals. The practical work this week is less about adoption and more about calibration: finding where the out-of-the-box assumption quietly misbills you.

Alibaba's open vision model overthinks by default; dial it down

Practitioners deploying Qwen 3.8 27B inherit an overthinking default that inflates runtime cost without warning.

Alibaba's Qwen 3.8 27B is an Apache-licensed vision model that runs on a laptop, but Simon Willison's hands-on test found the default reasoning setting consumed 22,276 thinking tokens to draw a simple SVG, taking 21 minutes. Switching to low reasoning cut that to two minutes. Load it in LM Studio, set reasoning to low, then judge quality against your workload.

Fred Schott brings React-style hooks to agent harness design

Agent configuration now shifts turn by turn, where static upfront setup was the only model.

Flue 2, from Astro creator Fred Schott, ships 16 built-in hooks (useSkill(), useTool(), useSubagent()) that let an agent reconfigure itself each turn rather than run from a fixed config. A single podcast interview supplies the detail. Raise the harness-first pattern at your next agent architecture review before committing to a static framework.

One in four ICML papers has a contested claim, large study finds

Research teams now inherit a 23% falsification rate as a documented baseline, not a rumour.

Hugging Face's community hackathon re-examined 2,200 ICML 2026 papers. One in four had at least one claim falsified or contested; confirmed failures include a theorem broken at step 224 and a headline result inflated threefold by evaluation padding. Check a paper's logbook entry before citing its results in a production decision.

AWS folds vector search into DynamoDB, removing a separate database dependency

DynamoDB retrieval pipelines now skip the separate vector store that synchronisation used to demand.

Until now, DynamoDB users copied embeddings to a separate vector database and kept two systems in sync. The new SearchVectors API stores and queries embeddings in the same table, supports up to 4,096 dimensions, and scales automatically. Test your query mix against the three per-byte cost meters before migrating a retrieval pipeline.
