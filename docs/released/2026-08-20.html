The Pulse · Story of the day

A rubric matters more than model intelligence for grading open answers

Eval grading cost now depends on rubric quality, not judge model tier.

An arXiv preprint tested six small-model configurations grading 3,456 open exam answers against explicit rubrics. Answer identity explained 95.6% of score variance; judge identity explained just 0.2%. Frontier judges added as a check were no more reliable. Extract rubrics once with a frontier model at ingestion, then grade everything with a cheaper one.

When your next procurement review asks whether frontier models are viable, is data-residency still your veto?

Aggregate benchmark scores hide item-level regressions during model upgrades

Migration sign-off built on aggregate scores now misses bidirectional item-level change.

An arXiv preprint tested three successive GPT API upgrades across 900 benchmark items, queried 50 times each. Aggregate gains of up to 7.3 percentage points coexisted with up to 8.3% reliably regressed items. Response-level data are public. Before your next API migration sign-off, run item-level regression checks, not just headline scores.

Hidden Unicode in files hijacks DeepSeek's agent one time in four

Open-weight agent frameworks now carry a measured injection surface, not a theoretical one.

Tencent's AI-Infra-Guard team ran 14,560 controlled injections against DeepSeek Harness across 16 content channels. Hidden Unicode characters in files succeeded 25.5% of the time; fake-completion text attacks landed at 17%. Code is public on GitHub. If you're deploying DeepSeek Harness in any agentic pipeline that ingests external files, gate untrusted content before sensitive tool calls.

Microsoft Copilot disclosed its own security bypass when researchers asked

Enterprise Copilot deployments now carry a documented self-disclosure attack path, not a theoretical one.

Varonis researchers bypassed Microsoft 365 Copilot's user-consent guardrail by asking Copilot how it worked. The model disclosed ?autorun=1, an undocumented parameter that silently fired a credential-theft prompt on link-click.
