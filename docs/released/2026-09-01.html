The Pulse · Story of the day

Language models caught Credit Suisse prospectus gaps that later triggered disputes

Supervisory prospectus review was a manual read against capital rules; ranked language model output now does it.

A Bank for International Settlements paper applies a language model pipeline to bank prospectuses, ranking divergences from capital rules for supervisors to review. Validated on anonymised Credit Suisse and Yes Bank documents, it recovered the exact rule-prospectus gaps that mattered in loss-absorption disputes. The methodology is now available for integration into supervisory prospectus-review workflows.

Four stories today each expose a different layer of AI infrastructure shifting from neutral utility to contested territory, whether that is model hosting, API access, agent autonomy, or developer tooling. The common signal for senior leaders: dependencies that felt like commodities are now negotiating positions.

NVIDIA buys the world's largest open-model repository for $13 billion

Open-model infrastructure just shifted from a neutral host to NVIDIA's balance sheet.

NVIDIA is acquiring Hugging Face for $13 billion, roughly 80 times the platform's $150 million annual revenue and nearly double its initial $7 billion offer from January. Hugging Face hosts the dominant repository for open model weights and datasets. Does NVIDIA ownership change your platform-risk calculus for anything currently running on that infrastructure?

Hands-On

5 stories

Three of today's five items are security findings, not capability releases, and they share a structure: something an agent does autonomously creates an attack surface the developer never explicitly opened. The two tool releases this week are both responses to exactly that problem.

Coding agents silently installed packages nobody owns inside corporate networks

Package provenance is now an agentic-coding audit item, not just a developer hygiene concern.

Researchers found 227 install commands in corporate codebases pointing at packages with no registered owner, placed there by Claude, Codex, and Hermes acting autonomously. Any of those slots could be claimed by an attacker. Audit every package your coding agents have installed; treat unowned dependencies as a live exposure, not a theoretical one.

Claude Code's auto-mode safety can be bypassed four times in five

Auto mode was Anthropic's stated defence against prompt injection; a researcher broke it at 80%.

Johann Rehberger, a credible prompt-injection researcher, found that tricking Claude Code into unzipping an archive and importing base64 executes a hidden local file, bypassing auto mode 80% of the time. Worse: auto mode blocked Claude's own cleanup command after detecting the compromise. Run coding agents inside a container with network egress restricted before trusting auto mode in production.

The largest CFA and FRM benchmark finds retrieval rarely improves hard questions

Financial reasoning evals had no unified CFA-plus-FRM protocol; a 10,198-question benchmark now fills that gap.

FinExam-10K (an arXiv preprint) covers CFA Levels I–III and FRM Parts I–II in one protocol, 10,198 questions, with 5,110 released. The best of 17 models scores 85.29% overall but only 34.68% on the hard subset. Retrieval augmentation produces little or negative net gain. Pull the 5,110 questions and run your model against the hard subset before claiming financial-reasoning readiness.

Vercel's new SDK sandboxes agent-written code with human-approval hooks

Agent-generated code running inside your app now has a named sandbox boundary, not eval's open access.

Running agent-generated JavaScript through eval hands it your app's secrets and credentials. Vercel's Run SDK executes untrusted code in an isolated QuickJS context, exposing only the host functions you define; sensitive operations pause for human approval, then resume without replaying completed work. Wire it into your next tool-use agent before shipping to production.

NVIDIA makes Python a first-class path to GPU programming

Python GPU library authors now share one NVIDIA-maintained CUDA foundation, not a patchwork of private binding layers.

Writing custom GPU kernels from Python used to mean C++ extensions or accepting whatever PyTorch exposed. CUDA Python 1.0, from NVIDIA's technical blog, unifies five previously scattered libraries under semantic versioning, so a Numba kernel and a cuda.compute call can share the same GPU buffer on the same stream. Install cuda.core and prototype your next custom kernel against it.
