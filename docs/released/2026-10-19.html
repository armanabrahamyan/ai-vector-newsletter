Edited open-model weights can carry silent backdoors undetected

Open-weight model vetting assumed weight editing was a safety concern, not a supply-chain one.

Abliteration — subtracting the refusal direction from a model's weights — is now routine on Hugging Face, and Schneier flags it as a supply-chain backdoor vector. Any fine-tuned, merged, or abliterated build can carry silent malicious edits. If your model-risk process doesn't include cryptographic weight verification, who in your org actually owns that check?

Redwood Research automates the search for gaps in agent safety monitors

Agent monitor red-teaming shifted from expert hours to an automated transcript-editing loop.

Monitors that watch AI agents for harmful behaviour can be fooled, and finding those gaps manually takes 2-3 hours per attack. Redwood's Screwtape pipeline edits real transcripts iteratively until a monitor fails; 252 runs on 94 transcripts found six confirmed attacks that evaded a frontier developer's monitor. Before your team certifies a monitor, who owns the red-teaming decision?

Halve agent serving costs by letting a small model do the drafting

Agent serving assumed one large model decoding every step; SpecAgent's reviewer pattern halves that decoding load.

SpecAgent (an arXiv preprint, code public on GitHub) splits agent work: a small model drafts tool-use steps and runs read-only calls, while a large model reviews the whole segment in one parallel pass. On τ²-Bench, it matches the large model's success rate at 41–54% of its wall time. The preprint and code are public on GitHub today.
