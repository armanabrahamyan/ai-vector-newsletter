LLM command-line tool now streams reasoning traces mid-run

LLM 0.32 (Simon Willison's open-source command-line tool for querying language models) now streams reasoning traces to standard error, keeping them out of piped output. It also adds server-side tools (code execution, web search) and a Git-style log store. Install via pip; use -R to suppress traces when piping output.

Alibaba's Qwen3.8-Max (2.4 trillion parameters, mixture-of-experts) matched Claude Opus 4.7 on the Vals Index at 66.1, with Vals running the comparison independently at $2.68 per test versus $6.17. LLM CLI plugin adds Claude 5 support with built-in web search

llm-anthropic 0.26 adds Claude Fable 5, Sonnet 5, and Opus 5 to Simon Willison's command-line tool, plus four server-side tools (WebSearch, WebFetch, CodeExecution, AnthropicMCP) via the -T flag. Claude Sonnet 5 and Opus 5 reason by default; pass -o thinking 0 to disable it. Fable 5 always reasons and the flag has no effect on it. Already using the CLI? Upgrade and swap -o web_search for -T WebSearch before your next agentic pipeline run.

kagent separates agent identity from Kubernetes Pods to cut waste

One Pod per agent wastes resources: agents are bursty, short-lived, and may spawn subagents or pause for human approval. kagent's Agent Substrate layer schedules logical Actors onto a fixed pool of long-lived worker Pods instead, decoupling agent identity from execution. Map your current Kubernetes agent deployment against this Actor/Worker model before your next architecture sprint.

Credit assignment is the problem. Agentic RL research is converging on a single unsolved question: which step actually mattered. One preprint, one benchmark; replicate before you redesign your training loop.

A training trick finds which agent decisions actually swing the outcome

Early signal: reinforcement learning for agents often fails to credit the pivotal turns that decide outcomes. An arXiv preprint introduces AgentOPSD, which uses recursive Bayesian updates to convert sparse rewards into per-turn credit scores, reaching 89.1% on ALFWorld. Replicated, this changes how you design agentic training loops; unreplicated, the benchmark suite becomes the story.
