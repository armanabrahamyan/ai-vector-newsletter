Currents

2 items

Both items today address the same structural gap: open-model agents break down on tasks that run long enough to encounter failure, and the field is now building the training infrastructure to fix that. Neither result is production-ready, but the direction is clear enough to track.

Coding agents can now learn to recover from mid-task failures

Terminal agents failed silently on long tasks; a self-recovery training loop now closes that gap.

Terminal agents handling long coding tasks often stall on command errors with no path back. ReTerm, an arXiv preprint, trains a 9-billion-parameter agent on its own failure states, forking each into multiple recovery attempts; the resulting model gains 14.6 points on a coding benchmark. Code, data, and weights are all public, benchmarked across five failure categories.

Dense per-step rewards make week-long agent tasks trainable

Long-horizon agent training lacked a verified dataset and a working recipe; both are now public.

Sparse rewards have long stalled open-model training on tasks that run hours or days. Tev-Gym (an arXiv preprint) supplies 1,170 verified environments across seven domains, plus a per-step reward-shaping method that makes otherwise-intractable tasks trainable. Weights for the 27-billion-parameter model are public on Hugging Face. The model scores 47.3 on the τ-bench agentic benchmark, topping all open-weight baselines.
