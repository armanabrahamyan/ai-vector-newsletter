OpenAI's AI found critical flaws threatening 70% of the web's servers

Critical web infrastructure now gets AI-driven security audits at a scale manual research never reached.

OpenAI's Patch the Planet programme used GPT-5.6 Sol to discover PHP2Shell: two memory-corruption vulnerabilities in PHP's core engine, with demonstrated unauthenticated remote code execution against WordPress, Drupal, and Joomla. Wiz independently found the same bugs. Two months of coordinated remediation preceded disclosure; these are researcher-reported exploit results, not confirmed mass exploitation.

A banking-agent benchmark finds outcome scoring misses up to 12% of failures

Banking agent evals scored only final records; procedure checking exposes a separate failure layer.

Standard agent benchmarks judge only the final state of a conversation. An arXiv preprint introduces TauIndianBankBench, 1,000 Indian retail-banking tasks where both procedure and outcome are scored. Between 6.5% and 12% of sessions pass outcome-only checks despite skipping required steps. Before signing off on a banking agent, demand procedure-aware evals.
