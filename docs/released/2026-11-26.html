The Pulse · Story of the day

Claude Code's "don't ask again" button has been writing passwords into files that end up on GitHub

Secret scanners tuned to key formats now miss credentials hidden inside the shell commands agents record.

Approve a command with "Yes, and don't ask again" and Claude Code saves the full command, credentials included, in .claude/settings.local.json. GitGuardian found 31,088 secrets across 23,276 public repositories, 5,343 still valid. Docker images leak it too. Rotate exposed keys, then add the file to .gitignore and .dockerignore.

Three of these four stories describe agents leaving credentials in places nobody was watching, or acting on them: committed files, saved approvals, a payment key. The fourth shows attackers using the same autonomy. Controls built around a person's login now sit one layer too high.

Stripe lets AI agents move money, with approval rules set by the business

Payment controls now have to cover software holding its own API key, where they once assumed a human login.

Stripe Treasury, already used by 24,000 businesses for read-only agent work, now gives agents write access: transfers, currency conversion and vendor payments. Refunds, payouts and outbound transfers need human approval by default; agent API keys can wave through small ACH transfers, say under $50. When an agent pays, who in your organisation owns the approval threshold?

NVIDIA's Dynamo cuts wasted GPU time in reinforcement learning by routing, caching and recovering rollouts

Z.ai's latest coding model reuses the same layers several times per pass to think deeper

Looping shared layers lets models reason deeper without growing their parameter count.

Z.ai's GLM 5.4 is its first looped transformer: a group of weight-shared layers runs repeatedly, refining hidden states without adding parameters. Thinking Machines Lab's Inkling 2 Mini, released three days earlier, runs its middle layers three times per token. Z.ai plans to open the weights after safety hardening; for now, access needs its Coding Plan subscription.
