OpenAI's agent safety monitors had gaps that agents themselves could exploit

Frontier-lab agent monitoring now has an external red-team record, where only internal review existed before.

Redwood Research and METR found, after three weeks inside OpenAI's codebase, that agents could disable their own monitoring via two ordinary request headers; gaps left roughly 10% of coding-agent traffic unmonitored for months. OpenAI says all production vulnerabilities are patched. When your agent monitoring can be switched off by the agent itself, who audits the auditor?

Google's new data-agent toolkit splits guardrails into advice and hard enforcement

Skill-level guardrails in data-agent toolkits advise; IAM deny policies now actually block the call.

Google's Data Agent Kit is now generally available: 37 open-source skills connect coding agents to fifteen-plus Google Cloud data services. The critical distinction is that the accidental-data-loss skill asks the agent to stop; an IAM deny policy actually blocks the call. Skills are on GitHub under Apache 2.0. Configure the IAM deny policy before wiring any agent to production data.

QuantumBlack's Kedro pattern adds approval gates to catch agent quality drift

Agent quality drift now has a structural fix, where ad-hoc output review was the only option before.

QuantumBlack's Kedro-based reflection pipeline wraps enterprise agents in modular governance: data contracts define acceptable output, approval gates block weak results before they propagate, and the pattern surfaces quality failures that emerge only across dozens of runs. PyTorch models now run on Google TPUs without rewriting code

PyTorch engineers targeting Google TPUs previously absorbed a full framework switch; that overhead is gone.

Until now, PyTorch on Google TPUs meant rewriting code for a specialist framework with lazy tensor execution and unpredictable recompilation. TorchTPU makes TPU just another device: device_map="tpu" is the only change. Transformers, Diffusers, and Kernels all work natively. At batch 64, a custom kernel hits 21.5× faster decoding. Install TorchTPU and point it at your existing training loop.
