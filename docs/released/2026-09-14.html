The CoTControl eval, used in OpenAI and Anthropic safety cases to argue frontier models can't hide their reasoning, is heavily prompt-sensitive. OpenRouter's automatic routing can silently change model behaviour mid-deployment

Automatic provider routing was a cost optimisation; it is also an unannounced behaviour swap.

OpenRouter promises a single endpoint with automatic fallback across providers, but Mohamed Moustafa documents a concrete catch: providers run different serving software, so the same model call can return different outputs, lose image-understanding support entirely, or handle reasoning-effort settings differently. Pin a specific backend with provider.only before shipping any production call that depends on image understanding or consistent reasoning behaviour.

Copying correct answers degrades reasoning; learning from self-made mistakes helps

Reasoning training was an imitation problem; Negative Self-Distillation reframes it as active avoidance.

Standard self-improvement training forces a model to imitate confident answers, suppressing the exploratory behaviour hard problems require. Negative Self-Distillation flips that: the model generates a 'careless reasoner' version of itself and trains away from it. A dynamic gate isolates reasoning tokens so fluency survives. The method is publicly documented on arXiv, with benchmark gains across five reasoning tasks.
